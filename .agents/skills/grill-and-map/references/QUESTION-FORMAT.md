# Question format

Use this structure for every question in a round, numbered from Q1.

```
❓ **Q1** - **<question title>**: <question body, may run to several paragraphs and offer choices>

➡️ <your recommended answer>
```

## Rules

- **Hold the spell.** No DDD vocabulary reaches the user. "Bounded context", "ubiquitous language", "anti-corruption layer", "aggregate" and the five relationship labels live in the files and never in a question.
- **Use the user's own nouns.** When they say "job", ask about jobs — never quietly substitute "order" because you prefer it. A noun you replaced is a seam you can no longer hear.
- **One question, one decision.** An "and" or an "or" in the question means it is two questions.
- **Recommendation is mandatory.** Never blank, never "it depends". If you are genuinely uncertain, state the assumption that drives the recommendation.
- **Name the constraint.** "It fits your constraints" is not a reason. Say which constraint, and how the recommendation satisfies it.
