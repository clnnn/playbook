# PRD

The PRD for this repo is one markdown file at `docs/prd.md`. The repo builds one product, so the file carries no subject in its name.

## When a skill says "publish the PRD"

Write `docs/prd.md`, creating `docs/` if needed. When the file already exists, show the user a diff and confirm before replacing it.

## When a skill says "read the PRD"

Read `docs/prd.md`. A missing file means no PRD has been written yet: say so and continue with what the user supplied.
